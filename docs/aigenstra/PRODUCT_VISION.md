# AIGENSTRA — PRODUCT VISION

## Executive Summary

**Aigenstra is a prompt builder, not an app builder.**

Aigenstra serves as the intelligent product-architecture and prompt-engineering guidance layer between a human user and an external AI coding agent (e.g. Google Antigravity, Claude Code, Cursor, Codex, Lovable, Gemini).

## Core Value Proposition

> **"You bring the idea. Aigenstra brings the product plan and the prompt. Your coding AI builds it."**

Beginners and vibe coders frequently struggle with AI coding tools not because the tools lack coding power, but because prompts are either vague, missing essential technical decisions, overflowing with irrelevant tokens, or skipping crucial architecture considerations (like server-side authorization, state handling, and data models).

Aigenstra bridges this gap:
1. **Guided Discovery:** Converts vague concepts into structured product blueprints without demanding technical jargon from the user.
2. **Deterministic Architecture:** Resolves authentication, data entities, UX journeys, security rules, and edge cases up front.
3. **Context Optimization:** Curates only the minimal, high-impact context required for each specific task to prevent context drift and wasteful token consumption.
4. **Agent-Specific Prompt Generation:** Formulates structured, production-grade 16-part prompts specifically formatted for the user's targeted coding agent.
5. **Closed-Loop Audit & Fixes:** Audits implemented code and outputs targeted, bite-sized fix prompts.

## Target Audience

- **Beginner & Intermediate Vibe Coders:** Users who want to build applications using AI agents but don't know how to architect databases, APIs, or security models.
- **Founders & Product Managers:** Non-technical or semi-technical creators who want to validate ideas, create PRDs, and guide coding agents with high fidelity.
- **Experienced Software Engineers:** Developers seeking rapid, token-optimized context extraction and structured prompt templates for complex features.

## What Aigenstra Is NOT

- Aigenstra is **NOT** a direct code editor or code execution platform.
- Aigenstra is **NOT** a website builder or no-code drag-and-drop SaaS builder.
- Aigenstra is **NOT** a generic, unstructured chatbot.
- Aigenstra is **NOT** a confusing multi-agent chat room exposing internal technical debates to the user.
